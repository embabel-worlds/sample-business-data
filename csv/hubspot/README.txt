HubSpot Sample Data

Sample HubSpot CRM data for testing, demos, and template purposes. 50 records per object.

Sheets included:
  • Contacts  50 people with names, emails, lifecycle stages, owners, sources, plus a free-form Notes field
  • Companies  50 organizations with industry, revenue, employees, lifecycle, plus a free-form Description field
  • Deals  50 deals across pipeline stages with amounts, probability, plus a free-form Description field

Free-form text fields:
  • Contacts → Notes (rep notes about the contact, last interaction, etc.)
  • Companies → Description (about the company, account context)
  • Deals → Description (deal context, stage notes, key dynamics)

Notes:
  • All data is fictional. Names, emails, and contact details are not real.
  • Field names match HubSpot's standard property labels for easy import/mapping.
  • Records are linked: Contacts ↔ Companies ↔ Deals via Record ID and name references.
  • Deals sheet includes a totals row with formulas for total pipeline + weighted pipeline.
